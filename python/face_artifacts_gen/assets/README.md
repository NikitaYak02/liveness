# Assets for procedural method

- `glasses/` — optional PNG frames with alpha (not required; frames are drawn procedurally)
- `occluders/` — RGBA PNGs (hands, objects) for NatOcc-style pasting; `hand.png` is a placeholder
- `env_maps/` — environment textures used as lens reflections; `window.png` is a placeholder

Drop your own cutouts here to improve realism without changing code.
